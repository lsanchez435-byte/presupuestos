# Mi presupuesto — interfaz web

Proyecto hecho con HTML, CSS y JavaScript puro, inspirado en el dibujo de referencia.

## Cómo abrirlo en Visual Studio Code
1. Descarga y descomprime `mi_presupuesto.zip`.
2. En Visual Studio Code, selecciona **Archivo > Abrir carpeta** y abre la carpeta `mi_presupuesto`.
3. Abre `index.html`.
4. Puedes abrirlo directamente en el navegador haciendo doble clic en `index.html`. También puedes instalar la extensión **Live Server**, hacer clic derecho sobre `index.html` y seleccionar **Open with Live Server**.

## Funciones
- Agregar compras con artículo, categoría, precio y estado.
- Editar, borrar y cambiar el estado de una compra.
- Ver totales de presupuesto, compras pagadas y pendientes.
- Consultar el resumen por categoría.
- Buscar y filtrar compras.
- Cambiar el presupuesto mensual.
- Guardar la información en `localStorage` del navegador.

## Archivos
- `index.html`: estructura de la interfaz.
- `styles.css`: diseño adaptable a celular y computador.
- `script.js`: lógica e interacción.
